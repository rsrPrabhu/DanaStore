# DanaStore

DanaStore is being developed from the DemoStore discovery findings. The project will help improve customer support for order-status and returns questions while protecting company customer terms.

## Current status

The project is in discovery and requirements definition. No application code has been added yet.

## Local development setup

This project uses a local Python virtual environment. From the project root:

```bash
source .venv/bin/activate
python --version
```

The `.venv` directory and local `.env` files are excluded from Git.
